Whisper Mood

Whisper Mood — клиент-серверное веб-приложение для ведения личного дневника настроения, сохранения мыслей и управления личными записями.

Проект разрабатывается в рамках дисциплины «Программная инженерия».

Возможности

* Регистрация и авторизация пользователей.
* Создание и просмотр записей дневника.
* Редактирование и удаление записей.
* Поиск записей.
* Работа с вложениями.
* Просмотр информации о встречах.
* Административное управление встречами.

Требования для запуска

На компьютере должны быть установлены:

* Git.
* Docker Desktop с работающим Docker Engine.
* Docker Compose.

Быстрый запуск

1. Клонирование репозитория

git clone --branch lab-1 https://github.com/pampixz/full-stack.git
cd full-stack

2. Запуск приложения

В PowerShell:

$env:OPENWEATHER_API_KEY = ""
docker compose up --build -d

Погодный API является дополнительной интеграцией. Для работы функции погоды может потребоваться действительный ключ OpenWeather.

3. Проверка контейнеров

docker compose ps

После запуска должны работать четыре сервиса:

Сервис Назначение Адрес
db MySQL localhost:3307
backend FastAPI http://localhost:8080
frontend Пользовательский интерфейс http://localhost:3000
proxy Nginx http://localhost:8088

Основной адрес приложения: http://localhost:8088

Проверка backend: http://localhost:8080/health

Smoke-тестирование

После запуска выполните следующие проверки:

1. Авторизация: зарегистрируйте тестового пользователя и войдите в систему.
2. Создание записи: создайте запись дневника и убедитесь, что она появилась в списке.
3. Изменение записи: отредактируйте созданную запись, сохраните изменения и затем удалите её.

Остановка приложения

docker compose down

Команда останавливает и удаляет контейнеры, сохраняя данные в именованном томе базы данных.
