# Паспорт проекта Whisper Mood

---

## 1. Общая информация

**Название:** Whisper Mood — веб-приложение для ведения личного дневника настроения.

**Происхождение:** собственный существующий проект, разработанный самостоятельно.

**Репозиторий:** [pampixz/full-stack](https://github.com/pampixz/full-stack).

**Тип приложения:** клиент-серверное веб-приложение.

**Состояние проекта:** существует реализованная версия приложения, требующая проверки воспроизводимости запуска, актуализации документации и совершенствования инженерных практик.

---

## 2. Назначение и решаемая проблема

**Whisper Mood** — веб-приложение для ведения личного электронного дневника, сохранения мыслей, событий и эмоциональных переживаний пользователя.

**Решаемая проблема:** отсутствие единого удобного пространства для систематического ведения личных записей, отслеживания эмоционального состояния и организации связанной с этим информации.

Приложение позволяет сохранять записи, просматривать их историю и управлять личными данными.

**Цель проекта:** создание удобной, безопасной и доступной веб-системы для ведения личного дневника с разграничением прав пользователей.

---

## 3. Целевая аудитория и пользовательские роли

**Целевая аудитория:** люди, желающие регулярно фиксировать свои мысли, эмоции, события и личные переживания.

### 3.1. Пользователь

- Регистрация и авторизация.
- Создание, просмотр, редактирование и удаление собственных записей.
- Поиск записей.
- Работа с вложениями.
- Просмотр доступной информации о встречах.

### 3.2. Администратор

- Авторизация в системе.
- Использование административных функций.
- Управление встречами.
- Выполнение предусмотренных системой операций администрирования.

---

## 4. Три основные функции проекта

1. **Регистрация и авторизация пользователей.** Создание учётной записи, вход в систему и разграничение доступа по ролям.
2. **Управление записями дневника.** Создание, просмотр, редактирование, удаление и поиск личных записей.
3. **Работа со встречами.** Просмотр информации о встречах и административные операции по управлению ими.

## 14. Первые наблюдения о проблемах проекта

### 14.1. Воспроизводимость сборки

**Наблюдение:** необходимо проверить фиксацию версий Python-зависимостей.

**Предлагаемое решение:** зафиксировать совместимые версии и проверить повторную установку.

### 14.2. Автоматизированное тестирование

**Наблюдение:** необходимо проверить полноту тестового покрытия и выполнение тестов в CI.

**Предлагаемое решение:** проанализировать и при необходимости дополнить тесты.

### 14.3. Управление конфигурацией

**Наблюдение:** необходимо проверить хранение настроек базы данных и секретов.

**Предлагаемое решение:** использовать переменные окружения и исключить секреты из репозитория.

> По результатам проверки создать минимум три GitHub Issues с метками `question` или `bug`.
