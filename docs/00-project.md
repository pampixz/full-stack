Паспорт проекта Mood Diary

1. Общая информация

Название проекта: Mood Diary.

Происхождение: собственный проект, разработанный с нуля. Не является форком стороннего репозитория.

Репозиторий: https://github.com/pampixz/full-stack

Тип проекта: веб-приложение.

Состав команды: 3 человека.

2. Назначение проекта

Mood Diary — веб-приложение для ведения личного дневника, фиксации эмоционального состояния и отслеживания повседневных событий.

Проект предназначен для пользователей, которые хотят сохранять личные записи, отмечать важные события, организовывать встречи и просматривать историю своей активности в одном приложении.

Основная задача проекта — предоставить удобный инструмент для систематизации личных записей и наблюдения за собственным эмоциональным состоянием.

3. Целевые пользователи и их роли

В приложении предусмотрены две основные роли пользователей:

1. Пользователь (User)

Обычный пользователь приложения. Имеет возможность:

* регистрироваться и авторизовываться;
* создавать личные записи;
* просматривать историю своих записей;
* редактировать и удалять собственные записи;
* прикреплять файлы к записям;
* просматривать информацию о встречах.

2. Администратор (Admin)

Пользователь с расширенными правами. Дополнительно имеет возможность:

* управлять ролями пользователей;
* создавать встречи;
* выполнять административные операции.

4. Основные функции проекта

1. Регистрация и авторизация пользователей с использованием JWT.
2. Создание, просмотр, редактирование и удаление записей личного дневника.
3. Прикрепление файлов к записям дневника.
4. Просмотр и фильтрация истории записей.
5. Управление встречами.
6. Разграничение прав доступа между пользователями и администраторами.
7. Получение информации о погоде через внешний сервис.
8. Управление ролями пользователей.

5. Технологический стек

Backend

* Python 3.11.
* FastAPI — разработка REST API.
* SQLAlchemy — взаимодействие с базой данных.
* PyMySQL — подключение к MySQL.
* JWT — механизм аутентификации.
* Pytest — автоматизированное тестирование.

Frontend

* React 19.
* TypeScript.
* Vite — инструмент сборки.
* Axios — выполнение HTTP-запросов.
* React Router — маршрутизация.
* Vitest — модульное тестирование.
* Playwright — end-to-end тестирование.

Инфраструктура

* MySQL 8 — реляционная база данных.
* Docker — контейнеризация.
* Docker Compose — управление контейнерами.
* Nginx — проксирование запросов.
* GitHub Actions — автоматизация проверок.
